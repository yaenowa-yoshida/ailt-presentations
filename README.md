## 新しい資料の作り方

1. `_template/` を `YYYY-MM-テーマ/` という名前でコピー
2. `<title>` と `<body data-title="…">` を書き換え
3. ひな形のレイアウト（自己紹介・箇条書き・時系列・数字・2カラム・まとめ・メッセージ・出典）から必要なものを使う

共通の見た目は `_theme/deck.css`、操作は `_theme/deck.js` にまとまっています。色を変えるときは `deck.css` 冒頭の `:root` だけを編集します。

## 使い方

`index.html` をブラウザで開くだけで動きます。

- `→` / `Space` / スライドの右外側をクリック: 次へ、`←` / スライドの左外側をクリック: 前へ（スライド内のクリックや文字の選択では移動しません）
- `F`: 全画面
- PDF化: ブラウザの印刷 → 「PDFに保存」（1スライド1ページ、背景のグラフィックをオン）
