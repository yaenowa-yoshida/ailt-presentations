## 文章のルール

スライドも台本も、AIが書いたような言い回しを避け、人が書いた自然な書き言葉にする。

避けるもの
- 「〜の正体」「答えはシンプル」「まさに」「〜こそが鍵」などの決め台詞
- 「AからBへ。」で終わる標語、「〜ではなく〜」の対比の連発
- 「──」の多用、見出しをコロン（：）で区切る書き方
- 何でも3つに並べる癖、太字や「」での強調のしすぎ
- 体言止めの連続、「〜な時代に」「〜が求められる」といった大きな言い方

心がけること
- 自分の言葉で書く。見立てや推測は「〜と思います」「私の見立てです」と書く
- 数字には出典を付け、言い切れないことは言い切らない
- 一文を短くし、話し言葉として読んで不自然でないかを確かめる

## 新しい資料の作り方

1. `_template/` を `YYYY-MM/`（発表の年月）という名前でコピー
2. `<title>` と `<body data-title="…">` を書き換え
3. ひな形のレイアウト（自己紹介・箇条書き・時系列・数字・2カラム・まとめ・メッセージ・出典）から必要なものを使う

共通の見た目は `_theme/deck.css`、操作は `_theme/deck.js` にまとまっています。色を変えるときは `deck.css` 冒頭の `:root` だけを編集します。

## 使い方

`index.html` をブラウザで開くだけで動きます。

- `→` / `Space` / スライドの右外側をクリック: 次へ、`←` / スライドの左外側をクリック: 前へ（スライド内のクリックや文字の選択では移動しません）
- `F`: 全画面
- スマホ: 縦向きではスライドが縦に並び、スクロールで読める（図は横スクロール）。横向きではスライド表示になる。右下の ‹ › ボタンか左右スワイプでページを移れる
- PDF化: ブラウザの印刷 → 「PDFに保存」（1スライド1ページ、背景のグラフィックをオン）
